Encripta el GitHub Token

Encripta un GitHub token i genera el fitxer ght.txt per utilitzar-lo amb el teu editor JSON.

NOTA:Fer això pot ser insegur. Per mantenir la seguretat, és important que 1) el token caduqui just desprès de FM, 2) la contrasenya sigui molt forta (20 caràcters aleatoris, o 6 paraules).
AES-GCM · SHA-256
El fitxer descarregat conté el token encriptat i es pot utilitzar directament com a ght.txt dins del projecte.
